## How to Use Past Sessions
When continuing work on a project:
1. Read `clients/<client>/PROJECT.md` for current status and data gaps
2. Read the latest session folder for detailed analysis
3. Check data status tracker before suggesting next steps

## Project Conventions
- Session folders: `YYYY-MM-DD_sessionNN/`
- Always save outputs in multiple formats: MD, CSV, JSON, HTML
- Generate PDF/DOCX using the script in `scripts/`
- Update PROJECT.md after each session
